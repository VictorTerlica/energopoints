# ЭнергоТочки — РП и ТП по координатам

Локальное Android-приложение на Kotlin + Jetpack Compose (Material 3) для поиска
энергетических точек (РП и ТП), просмотра координат, заметок и быстрого открытия
точки в Яндекс.Картах или Google Maps.

Приложение **не содержит** ваших реальных данных в репозитории и **не отправляет**
их в интернет автоматически. Файл `points.json` вы кладёте на телефон сами.
Координаты уходят в Яндекс.Карты или Google Maps только в момент, когда вы сами
нажимаете соответствующую кнопку.

---

## Возможности

- Выбор района (список строится из ключей JSON).
- Фильтр по типу: РП / ТП.
- Живой поиск по номеру и названию.
- Карточки с градиентной иконкой, районом, типом и бейджем принадлежности
  (РОССЕТИ — зелёный, ССК — синий).
- Подробности в `ModalBottomSheet`: координаты, примечание из JSON, личная заметка.
- Заметки хранятся локально в DataStore Preferences. Ключ:
  `note_<район>_<тип>_<код>` — одинаковые номера в разных районах не конфликтуют.
- Открытие в Яндекс.Картах (сначала долгота, потом широта) и Google Maps
  (`geo:` с fallback на `https://maps.google.com`).
- Светлая и тёмная тема, фирменные цвета: синий `#1565C0`, янтарный `#FFA000`.
- Кнопка «Перезагрузить данные» — перечитывает файл без перезапуска.
- Импорт `points.json` через системный файловый диалог (SAF) — работает на
  Android 11+ без разрешений на хранилище.
- Понятная инструкция, если файл не найден; демо-пример по желанию.
- Ошибки JSON показываются в `AlertDialog`, битые точки пропускаются с записью в Logcat.

## Приватность и безопасность

> **Главное правило: `points.json` не должен попасть в git, на GitHub или в APK.**

- В репозитории лежит только `app/src/main/assets/points.example.json` —
  обезличенный пример на 3 точки.
- Реальный `points.json` добавлен в `.gitignore` (включая `app/src/main/assets/points.json`).
- Приложение читает файл из приватной внешней папки:
  `Android/data/com.energypoints.finder/files/points.json`.
  На Android 10 и ниже она доступна файловому менеджеру/USB **без разрешений**.
  На Android 11+ ОС ограничивает прямой доступ к `Android/data`, поэтому в
  приложении есть импорт через **«Выбрать points.json»**: системный диалог даёт
  доступ только к выбранному файлу, и приложение копирует его в свою папку.
- Заметки хранятся только на устройстве, резервное копирование приложения отключено
  (`android:allowBackup="false"`).
- Нет аналитики, рекламы, сетевых запросов к вашим серверам. Разрешение `INTERNET`
  нужно только для открытия ссылок на карты. При нажатии кнопки карт координаты
  выбранной точки передаются соответствующему картографическому сервису
  (Яндекс или Google) — это обычное открытие ссылки, а не фоновая отправка данных.
- Не загружайте собранный APK, если собирали его с встроенным `assets/points.json`:
  файл попадёт внутрь APK. `.gitignore` игнорирует `*.apk`, но при загрузке через
  веб-интерфейс GitHub правила `.gitignore` не применяются — проверяйте вручную.

## Быстрый старт через GitHub (без Android Studio)

### 1. Подготовьте проект

1. Скачайте архив с проектом и распакуйте его.
2. **Не добавляйте** в папку свой `points.json` — он не нужен для сборки APK.

### 2. Загрузите проект на GitHub

1. Войдите на [github.com](https://github.com) → **New repository**.
2. Имя, например `energy-points`. Рекомендуется **Private**.
3. Не добавляйте README/.gitignore при создании — они уже есть в проекте.
4. На странице пустого репозитория: **Add file → Upload files**.
5. Перетащите **всё содержимое** распакованной папки, включая скрытые `.github`,
   `.gitignore`, `.gitattributes`, `gradlew` и папку `gradle`.
   - В Проводнике Windows включите показ скрытых элементов.
   - Убедитесь, что `.github/workflows/build-apk.yml` попал в репозиторий.
6. Внизу нажмите **Commit changes** в ветку `main`.

> Важно: веб-загрузка не учитывает `.gitignore`. Не перетаскивайте `points.json`,
> `local.properties`, папки `build/`/`.gradle/`, APK и ключи подписи.

Альтернатива для опытных: `git init`, `git add .`, `git commit`, `git push`.
`.gitignore` сам исключит секреты — но всё равно проверьте `git status`.

### 3. Запустите сборку

- Сборка запускается автоматически при push в `main`.
- Или вручную: вкладка **Actions** → **Build debug APK** → **Run workflow** →
  **Run workflow**.
- Дождитесь зелёной галочки (обычно 3–6 минут).

Если Actions выключены: **Settings → Actions → General → Allow all actions**.

### 4. Скачайте APK

1. Откройте завершённый запуск в **Actions**.
2. Внизу, в разделе **Artifacts**, скачайте `energy-points-debug-apk.zip`.
3. Распакуйте архив — внутри `app-debug.apk`.
4. Передайте APK на телефон и установите (разрешите установку из неизвестных
   источников для файлового менеджера/браузера).
5. Артефакт хранится **30 дней**.

### 5. Положите свой points.json на телефон

Папка создаётся при первом запуске приложения.

**Способ А — импорт через приложение (рекомендуется, работает на Android 11+):**

1. На экране «Нужен файл points.json» нажмите **«Выбрать points.json»**
   (или меню ⋮ → «Импортировать points.json»).
2. Выберите свой файл в Downloads, «Документах» или облачном хранилище.
3. Приложение само скопирует его в
   `Android/data/com.energypoints.finder/files/points.json` и сразу перечитает.
4. Разрешения на доступ к хранилищу не нужны: системный файловый диалог даёт
   доступ только к выбранному файлу.

**Способ Б — USB/MTP:**

1. Подключите телефон к компьютеру, выберите режим **Передача файлов (MTP)**.
2. Откройте `Внутренняя память → Android → data → com.energypoints.finder → files`.
   На Android 11+ эта папка может быть скрыта — тогда используйте способ А или Г.
3. Скопируйте туда `points.json` (кодировка UTF-8).
4. В приложении нажмите **«Перезагрузить данные»** (иконка обновления справа сверху).

**Способ В — «Открыть папку» (Android 10 и ниже):**

1. На экране «Нужен файл points.json» нажмите **«Открыть папку»**.
2. Если файловый менеджер открыл папку — скопируйте файл туда.
3. Вернитесь в приложение и нажмите **«Проверить снова»**.

На Android 11+ системный DocumentsUI может отказать в открытии `Android/data` —
это ограничение ОС, а не приложения. Используйте способ А.

**Способ Г — ADB (для продвинутых):**

```bash
adb push points.json /sdcard/Android/data/com.energypoints.finder/files/points.json
```

Нужна включённая отладка по USB. После копирования нажмите «Перезагрузить данные».

После копирования файл читается без разрешений: это приватная внешняя папка
приложения, а не общая память.

### 6. Если файла нет

Приложение покажет экран с инструкцией, кнопки **«Выбрать points.json»**,
**«Открыть папку»**, **«Проверить снова»** и **«Посмотреть демо-пример»**.
Демо-данные не подставляются автоматически: так вы сразу видите, что реальный
файл ещё не загружен. Демо можно открыть вручную, чтобы проверить интерфейс.

## Формат points.json

```json
{
  "Самарский": {
    "рп": [
      {
        "code": "РП-101",
        "type": "рп",
        "name": "РП-101 «Волжская»",
        "district": "Самарский",
        "latitude": 53.195873,
        "longitude": 50.100172,
        "note": "Питает центральную котельную.",
        "ownership": "РОССЕТИ"
      }
    ],
    "тп": [
      {
        "code": "ТП-204",
        "type": "тп",
        "name": "ТП-204 «Ленинградская»",
        "district": "Самарский",
        "latitude": 53.201034,
        "longitude": 50.110458,
        "note": "",
        "ownership": "РОССЕТИ"
      }
    ]
  },
  "Ленинский": {
    "рп": [],
    "тп": [
      {
        "code": "ТП-17",
        "type": "тп",
        "name": "ТП-17 «Молодогвардейская»",
        "district": "Ленинский",
        "latitude": 53.203801,
        "longitude": 50.090498,
        "note": "Проверить нагрузку.",
        "ownership": "ССК"
      }
    ]
  }
}
```

### Поля точки

| Поле | Обязательное | Описание |
|---|---|---|
| `code` | да | Номер/код, например `РП-101`. Пустой код — точка пропускается. |
| `type` | желательно | `рп` или `тп`. Если пусто — берётся из имени массива. |
| `name` | нет | Отображаемое название. Если пусто — показывается `code`. |
| `district` | нет | Для отображения. Фактический район берётся из ключа верхнего уровня. |
| `latitude` | да | Широта, число от −90 до 90. |
| `longitude` | да | Долгота, число от −180 до 180. |
| `note` | нет | Примечание из файла (не путать с личной заметкой). |
| `ownership` | нет | `РОССЕТИ`, `ССК` или иное значение. |

Допускается `latitude`/`longitude` строкой (`"53.195873"`) и с запятой (`"53,195873"`).

### Правила разбора

- Поддерживаются ключи районов `рп`/`тп` (регистр не важен), а также `rp`/`tp`.
- Точка с нечисловой координатой, отсутствующей координатой, пустым `code` или
  координатой вне диапазона **пропускается**, причина пишется в Logcat:
  тег `PointsRepository`.
- Дубли `type + code` внутри района пропускаются.
- Если JSON синтаксически битый — показывается `AlertDialog` с ошибкой.
- Если файл не найден — экран с инструкцией.
- Кодировка файла — UTF-8. BOM в начале поддерживается.

## Личные заметки

- Хранятся в DataStore Preferences, файл `user_notes.preferences_pb` во внутренней
  памяти приложения.
- Ключ: `note_<район>_<тип>_<код>`, например `note_Самарский_тп_ТП-204`.
- Заметки не синхронизируются и не попадают в APK.
- Удалить все заметки можно через **Настройки Android → Приложения →
  ЭнергоТочки → Память → Очистить данные** (удалятся и настройки).

## Карты

Яндекс.Карты (обратите внимание: **сначала долгота, потом широта**):

```
https://yandex.ru/maps/?pt=<lon>,<lat>&z=17&l=map&text=<название>
```

Google Maps:

```
geo:<lat>,<lon>?q=<lat>,<lon>
```

Если `geo:` не обрабатывается — открывается
`https://maps.google.com/?q=<lat>,<lon>`. Яндекс-ссылка открывается как https:
при установленном приложении система предложит Яндекс.Карты, иначе браузер.

## Локальная сборка (Android Studio)

1. Откройте папку проекта в Android Studio (JDK 17).
2. Дождитесь Gradle Sync. Wrapper сам скачает Gradle 8.4.
3. Для проверки интерфейса без реального файла нажмите «Посмотреть демо-пример».
4. Если нужен встроенный файл: положите `points.json` в
   `app/src/main/assets/points.json` **локально** и соберите APK.
   Не коммитьте его и не публикуйте APK с ним.
5. Сборка из терминала (нужен JDK 17):

```bash
chmod +x gradlew   # Linux/macOS; в Windows не требуется
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

На Windows: `gradlew.bat assembleDebug`.

## Частые проблемы

**«Нужен файл points.json», хотя файл скопирован**

- Проверьте точный путь: `Android/data/com.energypoints.finder/files/points.json`.
- Убедитесь, что файл называется именно `points.json`, а не `points.json.txt`.
- Нажмите «Перезагрузить данные» — перезапуск не обязателен.
- На Android 11+ файловые менеджеры могут создавать файл в другой папке или
  вообще не показывать `Android/data`. Надёжный путь — **«Выбрать points.json»**
  (импорт через системный диалог) или ADB.
- Если файл импортирован, но не читается, проверьте его содержимое: при ошибке
  JSON приложение покажет диалог с текстом ошибки и кнопку «Выбрать другой файл».

**APK не устанавливается**

- Разрешите установку из неизвестных источников.
- Удалите предыдущую версию с другим package name, если конфликтует подпись.
- Debug APK подписан debug-ключом; для обновления используйте тот же тип сборки.

**Сборка в Actions падает**

- Проверьте, что `gradlew` и `gradle/wrapper/gradle-wrapper.jar` загружены.
- Файл `gradlew` должен иметь LF-переводы строк (в проекте так и есть,
  `.gitattributes` помогает).
- Откройте лог шага **Build debug APK**; типичные причины — отсутствие
  `platforms;android-34` (шаг установки SDK уже включён) или синтаксис Kotlin.

**Точки пропали**

- Откройте Logcat, фильтр `PointsRepository`: там будет причина по каждой точке
  (нечисловая координата, пустой code, дубль, выход за диапазон).
- В интерфейсе показывается баннер «Пропущено точек: N».

**Яндекс.Карты не открываются**

- Ссылка https откроется в браузере, даже если приложение не установлено.
- Проверьте, что на телефоне есть браузер.

## Чек-лист перед публикацией репозитория

- [ ] `git status` не показывает `points.json`.
- [ ] В `app/src/main/assets/` нет `points.json` (только `points.example.json`).
- [ ] В репозитории нет `local.properties`, `build/`, `.gradle/`, APK, ключей.
- [ ] Если репозиторий публичный, в истории коммитов нет реальных адресов и кодов.
- [ ] Скачанный APK не содержит встроенного `points.json` (если не собирали с ним).
- [ ] Понимаете, что артефакты Actions доступны тем, у кого есть доступ к репозиторию.
